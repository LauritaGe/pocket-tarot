# Pocket Tarot

Los 22 Arcanos Mayores en una pantalla de tinta electrónica, como PWA instalable y offline.

- **Toque corto:** baraja y saca una carta (derecha o invertida) → relato de la carta → otra carta
- **Mantener:** vuelve al inicio
- Todo se dibuja desde bitmaps en hexadecimal: 22 cartas de 96×128 px, dorso de 120×150 px y tipografía de 5×10 px, sobre una pantalla de 152×296 px

## Instalar
- **iPhone:** abrir en Safari → Compartir → *Agregar a pantalla de inicio*
- **Android:** abrir en Chrome → *Instalar app*
